# Budget vs Actual P&L Dashboard (Power BI)

## Overview
Interactive financial dashboard showing monthly budget vs actual
performance across 5 departments with variance analysis.

## Features
- KPI Cards: Total Actual, Budget, Variance, Variance %
- Monthly Trend: Actual vs Budget line chart
- Department-wise Variance (colour-coded bar chart)
- P&L Matrix with drill-down
- Slicers for month and department filtering

## Tools
Power BI Desktop, DAX, Power Query

## Data
Synthetic P&L data (5 months, 5 departments)
